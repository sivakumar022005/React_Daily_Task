# 💰 Smart Expense Tracker

A responsive and user-friendly expense management application built using **React.js and Tailwind CSS**. This application helps users manage their income, track daily expenses, monitor their balance, and understand their spending activities.

## 🚀 Features

- **Dashboard Overview** – View total balance, income, expenses, and monthly expenses.
- **Add Transactions** – Add income and expense transactions.
- **Category Management** – Organize transactions by categories.
- **Transaction History** – View all financial activities.
- **Search Transactions** – Search transactions by name.
- **Filter Transactions** – Filter by income and expenses.
- **Delete Transactions** – Remove unwanted transactions.
- **Financial Overview** – Visualize income and expense proportions.
- **Local Storage** – Automatically save transaction data in the browser.
- **Responsive Design** – Works on desktop, tablet, and mobile devices.

## ⚙️ Installation and Setup



**1 Navigate to the project folder**

```bash
cd smart-expense-tracker
```

**2 Install dependencies**

```bash
npm install
```

**3. Install required packages**

```bash
npm install lucide-react
```

**4. Start the application**

```bash
npm start
```

For a Vite project, use:

```bash
npm run dev
```

## 💡 How It Works

1. Open the application dashboard.
2. View your total balance, income, and expenses.
3. Click the **Add Transaction** button.
4. Enter the transaction name, amount, type, category, and date.
5. Save the transaction.
6. View updated financial information on the dashboard.
7. Search, filter, or delete transactions whenever required.

## 📊 Key Functionalities

- Dynamic balance calculation using JavaScript `reduce()`.
- Transaction filtering using JavaScript `filter()`.
- Dynamic transaction rendering using React `map()`.
- State management using `useState()`.
- Automatic data saving using `useEffect()`.
- Browser-based data storage using LocalStorage.
